# 识艺 · 艺术概论刷题

一个面向艺术概论考试的纯选择题学习站。界面以 12 章为单位，提供单元练、疯狂混练、错题本、收藏、答题速度与学习记录。

[打开无需登录的独立网站](https://tunqigua.github.io/shiyi-art-theory/)

## 当前状态

- 已完成完整网站结构和交互。
- 内置 3 道明确标注的演示题，用于验证作答流程。
- 第 2–12 章显示为“等待正式题库”，不会用虚构内容填充。
- 学习数据保存在浏览器 `localStorage` 中。

## 题库接入

题库集中在 `dist/questions.js`。每道题使用以下结构：

```js
{
  id: "chapter-1-001",
  chapter: 1,
  stem: "题干",
  options: ["选项 A", "选项 B", "选项 C", "选项 D"],
  answer: 0,
  explanation: "答案解析",
  demo: false
}
```

`answer` 从 `0` 开始：`0` 代表 A，`1` 代表 B，以此类推。

## 本地查看

这是一个无构建步骤的静态站点。用任意静态文件服务器打开 `dist/` 即可。
