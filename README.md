## 题库接入

题库集中在 `dist/questions.js`。每道题使用以下结构：

```js
{
  id: "chapter-1-001",
  chapter: 1,
  stem: "题干",
  options: ["选项 A", "选项 B", "选项 C", "选项 D"],
  multiple: true,
  answers: [0, 2],
  explanation: "原书页码、题型、题号与参考答案",
  source: { page: 1, number: 1, kind: "m", part: null }
}
```

`answers` 从 `0` 开始：`0` 代表 A，`1` 代表 B，以此类推。单选只有一个元素，多选选完提交且必须全部选对。多空题每个空独立练习，保留原始题号和空序。

`data/source-questions.json` 保留修正识别错误后的原题、原书答案及待核对条目；不会公开原始照片。
