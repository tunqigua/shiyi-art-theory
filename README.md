## 题库接入

题库集中在 `dist/questions.js`。每道题使用以下结构：

```js
{
  id: "chapter-1-001",
  chapter: 1,
  stem: "题干",
  options: ["选项 A", "选项 B", "选项 C", "选项 D"],
  multiple: true,
  answers: [0, 2],
  explanation: "原书页码、题型、题号与参考答案",
  source: { page: 1, number: 1, kind: "m", part: null }
}
```

`answers` 从 `0` 开始：`0` 代表 A，`1` 代表 B，以此类推。单选只有一个元素，多选选完提交且必须全部选对。多空题每个空独立练习，保留原始题号和空序。

`data/source-questions.json` 保留修正识别错误后的原题、原书答案及待核对条目；不会公开原始照片。

## 检查

`TEST_URL=http://127.0.0.1:端口 node tests/mistake-explanations.cjs` 检查错题解析默认隐藏、旗标/题目点击及键盘展开收起、每题独立、重进收起、历史不变、完整解析与手机布局。

`node scripts/build-explanations.cjs` 将人工解析 `data/explanation-notes.txt` 与核对资料 `data/explanation-sources.json` 生成 `dist/explanations.js`，并检查所有练习项的考点和非应选项覆盖。拆空题按原题共用解析，在界面另标当前空序。

`TEST_URL=http://127.0.0.1:端口 node tests/explanations.cjs` 实测515题的答对/答错完整解析、1293个非应选项、出处、拆空、红绿边框及手机布局。

`node tests/question-stages.cjs` 检查十二章先单后多、疯狂混练5题轮换、余题与单一题型、文字提示与计时、键盘进入和手机布局。

`node tests/check-bank.cjs` 检查全部原题数量、重复、答案范围、选项对应、拆空顺序和待核对题隔离。

安装 Playwright 浏览器后，在本地启动 `dist/`，使用 `TEST_URL=http://127.0.0.1:端口 node tests/browser.cjs` 实测全部练习项的正确与错误答案、提交、记录恢复和移动端布局。

`node tests/updates.cjs` 检查新答案迁移、错题名录、红绿实色、每日时长、跨午夜分摊、后台暂停及历史持久化。更正前未保留选择的早期记录无法可靠重判，仍保留原记录；不会清空收藏和学习历史。

`node tests/calendar.cjs` 检查北京时间、日期格对齐、翻月跨年与闰年、每日对错累计、旧记录迁移、500条截断后统计保留及手机排版。
